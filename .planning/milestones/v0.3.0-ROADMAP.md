# Milestone v0.3.0: Adaptive UX Hardening And Launcher Ergonomics

**Status:** SHIPPED 2026-04-14  
**Phases:** 11-14  
**Total Plans:** 17

## Overview

`v0.3.0` hardened FMCL where the launcher still felt unreliable in day-to-day use. The milestone made the shell and primary controls adaptive, repaired preset-theme truth across light and dark mode, flattened common settings tasks, made launch progress explicit, improved modpack ergonomics, and closed on multi-size browser evidence plus a green packaging-aware gate.

## Milestone Summary

**Key Accomplishments:**

- Adaptive shell and overlay behavior now hold together at first-launch default bounds and narrower desktop widths.
- Preset themes apply truthfully in both light and dark mode without unreadable white-on-white surfaces.
- Settings navigation is flatter for common tasks, and launch-state feedback is explicit instead of ambiguous.
- Modpack creation, browsing, and installed-pack quick actions are more dependable and easier to understand.
- The milestone closed on multi-size browser evidence, refreshed public docs, and a green packaging-aware gate.

**Key Decisions:**

- Keep the milestone inside the existing Electron + React + TypeScript architecture.
- Express adaptive layout and overlay safety through shared seams instead of per-screen breakpoint patches.
- Make launch truth and modpack ergonomics clearer inside the existing flows before considering a dedicated activity center or deeper redesign.
- Reuse one manual verification seam for milestone closeout and keep future parity ideas as bounded follow-up work instead of silent scope creep.

**Issues Resolved:**

- Non-adaptive layouts, mixed control sizing, and viewport overflow on shipped surfaces.
- Preset-theme behavior that was previously incomplete or misleading across light and dark mode.
- Overly nested settings navigation for common launcher tasks.
- Unclear launch progress and unstable local or remote modpack interaction seams.
- Placeholder or fallback asset leaks on shipped classic launcher surfaces.

**Issues Deferred:**

- Automated visual-regression coverage for milestone-owned surfaces.
- Richer modpack metadata, dependency context, and changelog detail in browser and install flows.
- Dedicated activity-center UX for downloads, installs, and background tasks.
- Additional dashboard density or layout presets and deeper account or session conveniences.

**Technical Debt Incurred:**

- Renderer build still emits a large chunk warning.
- `package.json` still lacks `description` and `author`, producing non-blocking electron-builder warnings.
- GSD workflow metadata still drifts in places (`milestone-op` stale version reporting and Phase 13/14 summary frontmatter mismatch with `summary-extract` expectations).

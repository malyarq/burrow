# Приватность и аналитика

Burrow полноценно работает без аналитики. В официальной сборке при первом запуске показаны два явных варианта: **Включить аналитику** и **Не отправлять**. До положительного выбора события не отправляются и идентификатор не создаётся. Выбор можно изменить в разделе **Настройки → Лаунчер → Приватность и обратная связь**.

## Что отправляется

Официальные сборки используют PostHog EU Cloud и фиксированный проверяемый список событий. У каждого события есть время, версия Burrow, семейство ОС, версия схемы и случайный идентификатор установки. Дополнительные свойства ограничены белым списком во время выполнения:

| Группа | Разрешённые свойства |
| --- | --- |
| Согласие и открытие приложения | Источник согласия, язык, режим интерфейса и диапазон времени запуска |
| Запуск Minecraft | Семейство модлоадера, активность Burrow Link, результат, ограниченный этап ошибки и диапазон длительности |
| Первый запуск | Показ и ограниченное действие: игра, модпаки, Burrow Link, настройки или добровольный обзор |
| Ошибка интерфейса | Только поверхность, доступный способ восстановления и результат восстановления; без текста и стека ошибки |
| Операции с модпаками | Ограниченные тип, результат и диапазон длительности; без идентификаторов проекта, сборки и файла |
| Каталог модпаков | Провайдер, успешность, наличие запроса и фильтров, диапазоны числа результатов и длительности; без текста запроса и идентификатора проекта |
| Обновление Burrow | Источник проверки, этап, безопасная версия назначения и диапазон длительности загрузки |
| Burrow Link | Роль, этап, ограниченный код диагностики, direct/relay/unknown, диапазоны длительности, трафика, пикового числа участников и игровых подключений, признак квалифицированной сессии |
| Сеть, резервная копия и обратная связь | Выбранный режим сети, факт экспорта/импорта и фиксированный источник открытия GitHub |

Длительность, объём трафика и количества отправляются только диапазонами. Квалифицированной считается сессия Burrow Link, в которой было игровое подключение, прошёл трафик и соединение длилось не меньше минуты. Содержимое игрового трафика не читается.

Для сопоставления двух сторон одной попытки Burrow Link используется укороченный SHA-256 от случайного 256-битного кода комнаты с отдельным пространством имён. Сам код комнаты не отправляется. Такой идентификатор не используется для соединения, не раскрывает адреса участников и меняется вместе с комнатой.

## Локальные данные и доставка

Случайный идентификатор установки создаётся только после согласия и не вычисляется из оборудования, аккаунта, ника или пути. События отправляются как анонимные/personless: Burrow не вызывает `identify`, а каждое событие содержит `$process_person_profile: false` и `$geoip_disable: true`.

Если сеть недоступна, на компьютере остаётся не больше 100 уже очищенных событий не старше 7 дней. У каждого есть случайный `$insert_id`, поэтому повторная доставка не должна создавать дубль. После отказа от аналитики очередь и идентификатор сразу удаляются. Существенное расширение схемы повышает версию согласия и снова требует явного выбора.

Burrow **не отправляет** IP, геолокацию, данные аккаунтов, ники, токены, коды комнат, адреса серверов, пути, имена файлов, тексты запросов, логи, содержимое форм, тексты или стеки ошибок, скриншоты, запись сессии и содержимое сетевого трафика. Нет PostHog SDK, autocapture, cookies, heatmaps, session replay или удалённого включения аналитики.

При HTTPS-запросе процессор технически видит сетевые метаданные. Проект Burrow должен находиться в EU-регионе, отбрасывать IP, не создавать person profiles и хранить события не дольше 12 месяцев. Код приложения выставляет защитные свойства, но не может проверить облачные настройки — их проверяет владелец каждого публичного релиза.

## Отчёты о проблемах

Кнопка **Сообщить о проблеме на GitHub** локально готовит предпросмотр только с версией Burrow, семейством ОС, языком и состоянием аналитики. Автоматической отправки нет: пользователь сам проверяет, редактирует и отправляет черновик по правилам GitHub.

Не добавляйте в публичный issue учётные данные, коды комнат, приватные адреса, личные пути или сведения об уязвимости. Об уязвимостях сообщайте через [приватный канал](https://github.com/malyarq/burrow/security/advisories/new).

## Управление и вопросы

- Выберите **Не отправлять**, чтобы не создавать и не отправлять продуктовые события.
- Выключите аналитику позже, чтобы прекратить сбор и удалить очередь с идентификатором.
- Если вы сами отправили информацию на GitHub, удалите issue или комментарий средствами GitHub.
- Задайте вопрос через [GitHub Issue](https://github.com/malyarq/burrow/issues/new), не добавляя личные данные.

Документ описывает текущую реализацию. Изменение состава данных требует одновременно обновить контракт, тесты, переводы и это уведомление до релиза.

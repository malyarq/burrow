# Milestone v0.2.0: UI System And Experience Rework

**Status:** SHIPPED 2026-04-13  
**Phases:** 7-10  
**Total Plans:** 17

## Overview

`v0.2.0` turned FMCL from a functionally broad but visually inconsistent launcher into a coherent product surface. The milestone established a shared UI system, rolled that system through the core and secondary launcher routes, verified the shipped experience through a reusable browser-backed walkthrough seam, and closed with truthful release documentation plus a green packaging-aware repository gate.

## Milestone Summary

**Key Accomplishments:**

- Established a shared UI language for shell chrome, cards, dialogs, forms, feedback states, and theme behavior.
- Refreshed the highest-traffic launcher routes with synchronized EN and RU copy and consistent route truth.
- Brought secondary surfaces such as share, screenshots, mirrors, statistics, and datapack management onto the same visual and accessibility standard.
- Added a reusable browser-backed manual verification seam and captured evidence across all milestone-owned routes.
- Refreshed release-facing docs so README and both public roadmap files describe the shipped launcher truth instead of stale plans.

**Key Decisions:**

- Keep the milestone brownfield-safe inside the existing Electron + React + TypeScript architecture.
- Treat FMCL as a modpack-first launcher while still preserving the simple-play flow.
- Require manual browser verification in addition to repo gates for a UI-heavy milestone.
- Refresh public docs from walkthrough evidence before claiming the milestone complete.

**Issues Resolved:**

- Mixed visual systems across launcher routes and secondary surfaces.
- Theme and accent behavior that previously affected only isolated parts of the launcher.
- Placeholder-heavy or stale EN/RU UI copy on refreshed routes.
- Missing release-truth evidence for the shipped UI redesign.

**Issues Deferred:**

- Automated visual-regression infrastructure as a future milestone concern.
- Richer theme packs, extra locales, and deeper personalization beyond the base token system.

**Technical Debt Incurred:**

- Renderer build still emits a large chunk warning.
- `package.json` still lacks `description` and `author`, producing non-blocking electron-builder warnings.
- Phase directories were intentionally left in `.planning/phases/` and not moved into an archive subdirectory during closeout.
